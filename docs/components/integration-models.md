## NuciSearch Integration

### Service Overview

| Property | Value |
|----------|-------|
| **Service** | NuciSearch |
| **Base URL** | `https://search.nucilandia.ro` |
| **Endpoint** | `/?q=[encoded-query]` (GET) |
| **Protocol** | HTTPS |
| **Integration type** | Anchor navigation (`target="_blank"`) |
| **Authentication** | None |
| **Rate limits** | Unknown (public service) |
| **SLA** | None (best-effort) |

### Request Model

**Generated by `script.js` for each word:**

```javascript
const url = 'https://search.nucilandia.ro?q=' + encodeURIComponent(query);
```

**Query formats:**

| Word Type | Query Template | Example |
|-----------|----------------|---------|
| Single word | `[word] DEX` | `kilometru DEX` |
| Infinitive ("a " + verb) | `[phrase] DEX` | `a urca DEX` |
| Multi-word phrase | `Definiție: [phrase]` | `Definiție: polul Nord` |

**URL encoding**: `encodeURIComponent()` applied to full query string.

**Special characters handled**: Spaces → `%20`, diacritics (ă, â, î, ș, ț) → UTF-8 percent-encoded.

### Response Model

**Not handled by application** — NuciSearch returns HTML page rendered in new browser tab.

**Expected response**: Search results page for the query.

**Error cases** (not handled):
- Network failure → Browser shows "Unable to connect"
- Service down → Browser shows error page
- Empty results → NuciSearch shows "No results"

### Link Generation

```javascript
'<a href="' + url + '" target="_blank" rel="noopener noreferrer">' + escapedText + '</a>'
```

**Security attributes:**
- `target="_blank"` — Opens in new tab
- `rel="noopener noreferrer"` — Prevents `window.opener` access, no referrer sent

**Content**: HTML-escaped original word text (via `$('<span>').text(wordText).html()`)

### Integration Contract

| Aspect | Application Responsibility | NuciSearch Responsibility |
|--------|---------------------------|---------------------------|
| Query formatting | ✅ Determines format, encodes | ❌ |
| Navigation | ✅ Creates anchor, opens tab | ❌ |
| Search execution | ❌ | ✅ Processes query, returns results |
| Result rendering | ❌ | ✅ Renders HTML page |
| Error handling | ❌ (browser default) | ✅ (service errors) |
| Availability | ❌ | ✅ |

### Failure Modes

| Failure | User Experience | Application Impact |
|---------|-----------------|-------------------|
| NuciSearch down | Word link opens error page | None (fire-and-forget) |
| Network offline | Browser "No internet" page | None |
| Query too long | Truncated/rejected by service | None (max ~100 chars) |
| Special chars broken | Wrong results | Low (encoding is standard) |

### Alternative Providers (Not Implemented)

The integration is hardcoded to NuciSearch. To change providers:

1. Modify base URL in `script.js`: `'https://search.nucilandia.ro?q='`
2. Adjust query format logic if provider expects different syntax
3. Update any provider-specific parameters

**Potential alternatives**: DexOnline, Google Dictionary API, Wikipedia API, custom backend.

## Security Considerations

### CDN Risks

- **No Subresource Integrity (SRI)** — Compromised CDN could inject malicious code
- **No CSP** — Browser cannot restrict script sources
- **Third-party trust** — cdnjs.cloudflare.com trusted for all 3 libraries

### NuciSearch Risks

- **Open redirect** — Not applicable (fixed base URL)
- **Query injection** — `encodeURIComponent()` prevents URL manipulation
- **Referrer leakage** — `rel="noreferrer"` prevents referrer header
- **Window.opener** — `rel="noopener"` prevents reverse access

### Recommended Hardening

1. **Add SRI hashes** to all CDN `<script>` and `<link>` tags
2. **Add CSP header** when served via HTTP server:
   ```
   Content-Security-Policy: default-src 'self'; script-src 'self' https://cdnjs.cloudflare.com; style-src 'self' https://cdnjs.cloudflare.com; font-src https://cdnjs.cloudflare.com; connect-src 'none'; frame-ancestors 'none';
   ```
3. **Remove unused jQuery Easing** dependency
4. **Consider local copies** for critical dependencies (jQuery)

## Extension Points

1. **Multiple search providers**: Add provider selector, configure per-provider query formats
2. **Fallback providers**: Try primary, fall back to secondary on error (requires fetch + error handling)
3. **Local search index**: Bundle dictionary data for offline use
4. **Analytics on searches**: Track which words users look up (privacy-opt-in)
5. **Custom search parameters**: Add filters (part of speech, language, etc.)
