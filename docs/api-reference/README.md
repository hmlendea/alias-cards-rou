# API Reference

## Overview

This application has **no traditional API** (no REST endpoints, GraphQL, gRPC, WebSocket, etc.).

It is a client-side only static site. All "API" interactions are:

1. **NuciSearch** — URL-based navigation (documented in [api-usage-examples.md](../api-usage-examples.md))
2. **GitHub** — Repository link
3. **Ko-fi** — Donation link
3. **CDNs** — jQuery, Font Awesome resources
